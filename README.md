# Duty-Gap-Lab

找出「排勤時段有上班、卻沒有登打工作紀錄」的漏打時段。純網頁，資料只在瀏覽器內處理。

## 使用方式

1. **點選排勤時段**：選月份（依勤務日 08:00–隔日 08:00），在網格上拖曳框選，或點班型拿起刷子再點或拖過日期列，整天換成該班型（預設日班 08–20、晚班 20–08，外加清空用的「休」；可在「管理班型」增刪）。沒拿刷子時可拖曳框選零碎時段。排勤與班型會記在這台電腦的瀏覽器。
2. **貼上工作紀錄**：從 Excel 整片複製貼上，工具會自動抓出 `115/10/24 08:00 ~ 115/10/24 10:00` 這種起訖時間。紀錄不保存。
3. **看結果**：紅＝漏打、橘＝部分漏打、灰＝排勤外紀錄（不算錯），下方列出每段漏打時段。

## 開發

- `core.js`：解析與比對邏輯（無 DOM）
- `app.js`：畫面
- 測試：`node tests/core.test.js`
- 用語見 `GLOSSARY.md`，決策見 `docs/adr/`

> 改了 `style.css`、`core.js`、`app.js` 時，要把 `index.html` 裡的 `?v=` 數字加一，避免瀏覽器用到舊的快取檔案。
